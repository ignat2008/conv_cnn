# PyTorch: от логистической регрессии до LeNet

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/ignat2008/conv_cnn/blob/main/pytorch_fc_cnn_mnist.ipynb)

Нейронные сети на PyTorch на двух наборах данных: от логистической регрессии, написанной вручную, до свёрточной сети LeNet на MNIST. В каждом эксперименте один и тот же путь: подготовка данных → модель → функции обучения и предсказания → обучение и оценка.

## Результаты

Accuracy на валидационной выборке (seed = 42):

| Данные | Модель | Accuracy |
|---|---|---|
| Moons | логистическая регрессия на `nn.Parameter` (3 параметра) | 0.8852 |
| MNIST | `784 → 128 → 128 → 10`, ELU, Adam, 10 эпох | 0.9725 (максимум 0.9792 на 9-й эпохе) |
| MNIST | `784 → 128 → act → 10`, act = тождественная | 0.9171 |
| MNIST | то же, act = ReLU | 0.9708 |
| MNIST | то же, act = Tanh | 0.9725 |
| MNIST | то же, act = LeakyReLU | **0.9751** |
| MNIST | LeNet (свёртки 3×3), 10 эпох | **0.9896** (максимум 0.9905 на 8-й эпохе) |

Значения после последней эпохи. Кривая ELU получена на сети с двумя скрытыми слоями, поэтому её сравнение с остальными активациями приблизительное.

## Что сделано

1. **Moons.** Линейный слой вручную ($logits = XW + b$, без `nn.Linear`), `BCEWithLogitsLoss`, цикл обучения с остановкой по сходимости лосса, визуализация границы решения, `Dataset` / `DataLoader`.
2. **MNIST, полносвязные сети.** Функции `fit_one_epoch`, `eval_one_epoch`, `train_func`; сравнение активаций (тождественная, ReLU, Leaky ReLU, ELU, Tanh); собственные реализации Leaky ReLU и Tanh с аналитическими градиентами, проверка по значениям и градиентам PyTorch.
3. **Свёрточные сети.** Применение ядер свёртки (тождественное, границы, резкость, размытие) к изображению; LeNet на модулях `nn.Module` с валидацией каждые `n` эпох и сохранением весов на промежуточных эпохах.

## Как запустить

Проще всего открыть ноутбук в Google Colab по кнопке выше (подойдёт и CPU, на GPU быстрее).

Локально:

```bash
pip install -r requirements.txt
jupyter notebook pytorch_fc_cnn_mnist.ipynb
```

MNIST скачивается автоматически через `torchvision`. Фотография для экспериментов с ядрами загружается командой `wget` из репозитория OpenCV (в Windows используйте `curl` или скачайте файл вручную).

## Ограничения

- в качестве валидации используется тестовая часть MNIST: она служит и для наблюдения за обучением, и для итоговой оценки;
- все эксперименты выполнены на одном seed, разброс между запусками не оценивался;
- сравнение активаций приблизительное: ELU обучалась на более глубокой сети, чем остальные.
